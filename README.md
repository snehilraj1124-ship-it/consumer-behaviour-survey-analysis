# 🛍️ Consumer Behaviour Survey & Analytics

## 📊 Project Overview

This project is an end-to-end **Consumer Behaviour Survey and Analytics** solution designed to understand customer preferences, shopping behaviour, spending patterns, payment preferences, satisfaction levels, loyalty and repeat-purchase behaviour.

The project uses a synthetic survey dataset containing **1,200 consumer responses** and combines multiple technologies to demonstrate a complete data analytics workflow.

### Technologies Used

- 🐍 Python
- ☕ Java
- 🗄️ SQL
- 📊 Microsoft Excel
- 🌐 HTML5
- 🎨 CSS3
- ⚡ JavaScript

The project covers the complete journey from **raw survey data → data validation → analysis → customer segmentation → SQL reporting → Excel analysis → web dashboard**.

> **Note:** This is an educational portfolio project using completely synthetic data. The dataset does not represent real customers, real transactions or an actual market survey.

---

# 🎯 Project Objectives

The primary objective of this project is to analyze consumer behaviour and identify patterns that can support business and marketing decisions.

The project focuses on:

- Understanding consumer demographics
- Identifying preferred product categories
- Analyzing shopping frequency
- Studying monthly consumer spending
- Understanding product discovery channels
- Analyzing payment-method preferences
- Measuring customer satisfaction
- Studying customer loyalty
- Understanding discount preferences
- Analyzing repeat-purchase behaviour
- Segmenting customers based on behavioural characteristics
- Creating business-oriented analytical reports
- Presenting insights through an interactive web dashboard

# 📁 Dataset

The project contains a synthetic survey dataset with:

**1,200 respondents**

Each respondent is represented by multiple demographic, behavioural and purchasing attributes.

### Major Dataset Fields

| Field | Description |
|---|---|
| Respondent_ID | Unique respondent identifier |
| Age_Group | Age segment |
| Gender | Gender category |
| City | Respondent city |
| Income_Band | Annual income category |
| Discovery_Channel | Primary product discovery channel |
| Preferred_Category | Preferred shopping category |
| Monthly_Spend_INR | Estimated monthly spending |
| Purchase_Frequency | Approximate monthly purchase frequency |
| Payment_Method | Preferred payment method |
| Satisfaction | Overall satisfaction level |
| Loyalty_Level | Customer loyalty classification |
| Discount_Preference_Pct | Preferred discount percentage |
| Repeat_Purchase | Repeat purchase intention |
